# 데이터ㆍAI 시스템 아키텍트를 위한 실무 가이드

![data-ai-system](data-ai-system.jpg)

이 문서는 **「데이터ㆍAI 시스템 아키텍트를 위한 실무 가이드」** 책의 내용을 보조하기 위한 **참고자료**입니다. 독자가 책의 핵심 내용을 보다 쉽게 이해하고 확장 학습할 수 있도록 작성되었습니다. 아래 구성 요소들은 **언제든지 추가되거나 변경될 수 있으며**, 책의 최신 개정판 및 보완 자료와 함께 지속적으로 업데이트될 예정입니다.

## 참고자료

책의 흐름을 따라 1부(기초) → 2부(실전) → 3부(시스템 아키텍처) 순으로 정리했습니다. 각 문서는 관련 챕터를 읽은 뒤 확장 학습용으로 참고하면 좋습니다.

### 읽기 순서

문서들은 다음 갈래로 이어 읽을 수 있습니다.

- **모델 → 서빙**: 모델 구조 이해하기 → 모델 변환과 경량화 실습 → 모델 서빙 시 트레이드오프 → LLM 추론 서빙 최적화 → 소형 언어 모델과 온디바이스 추론
- **데이터 플랫폼**: 데이터 계약과 스키마 진화 → 오픈 테이블 포맷과 카탈로그 표준 → 텍스트-투-SQL과 시맨틱 레이어
- **LLM 애플리케이션 설계**: 시스템 프롬프트 템플릿 → 컨텍스트 엔지니어링 → RAG 품질 저하 요인 → 멀티모달 RAG → LLM 에이전트 아키텍처 → MCP 서버 설계
- **LLM 애플리케이션 운영**: RAG·LLM 평가 하네스 → 에이전트 관측성과 운영 → 프롬프트 인젠션과 가드레일 → 에이전트 코딩 워크플로

논문 읽기 가이드는 모든 문서의 참고 논문을 읽을 때 활용할 수 있습니다.
